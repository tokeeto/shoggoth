# Keyboard shortcuts and command line

[← Back to the manual](manual.md)

On macOS, use **Cmd** where this page says **Ctrl**.

## Everywhere

| Shortcut | Action |
|---|---|
| Ctrl+P | Command palette: find any command by name |
| Ctrl+R | Go to a card, encounter set, guide or project |
| Ctrl+N | New card |
| Ctrl+S | Save |
| Ctrl+Shift+S | Save project as |
| Ctrl+O | Open project |
| Ctrl+K | Show or hide the project tree |
| Ctrl+M | Number all cards |
| Ctrl+E | Quick export the current card |
| Ctrl+Shift+E | Export project |
| Mouse back / forward | Go back or forward through the pages you've viewed |

## In card text fields

| Shortcut | Action |
|---|---|
| Ctrl+B / Ctrl+I / Ctrl+T | Bold / italic / trait |
| Ctrl+L | Insert a reference to a card, set or project |
| Ctrl+Space | Snippets |
| Enter | New paragraph |
| Shift+Enter | Line break |
| Shift+Space | Non-breaking space |
| `<` | Tag suggestions (Enter or Tab to insert) |

## In the guide editor

| Shortcut | Action |
|---|---|
| Ctrl+B / Ctrl+I / Ctrl+T | Bold / italic / trait |
| Ctrl+1 … Ctrl+5 | Heading level 1–5 |

## In the location view

| Shortcut | Action |
|---|---|
| Drag / right-drag | Move a location / connect two locations |
| Mouse wheel | Zoom |
| F / Shift+F | Flip the location under the mouse / all locations |
| H / Shift+H | Hide the location under the mouse / toggle whether hidden locations are shown |
| Delete | Delete the selected free-standing arrows |

## Command line

| Command | Action |
|---|---|
| `shoggoth` | Start Shoggoth |
| `shoggoth -r FILE` | Render all cards in a project to images, without opening a window. See [Working with the project file directly](project-files.md#rendering-from-the-command-line) for the options. |
| `shoggoth -d FILE` | Display mode: preview the last-edited card in the terminal |
| `shoggoth -re 1` | Download the asset pack again on the next start |
| `shoggoth --help` | List every option |
